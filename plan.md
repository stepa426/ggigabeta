# Charactera — план реализации

## Цель

Русскоязычный mobile-first веб-сервис с ИИ-персонажами: каталог, профиль персонажа, личный чат, история общения, создание своих персонажей и профиль пользователя. Приложенный APK и gigaguru.tech используются только как функциональные ориентиры; закрытый код и ассеты не копируются.

## Реализация

Фронтенд — React + TypeScript + Tailwind в существующем шаблоне Webdev. Сервер — Express + tRPC. Пользовательская авторизация использует встроенный OAuth-сессионный контур проекта, а публичный интерфейс готов к явной маркировке входа через Google; отдельный SMS-вход будет подключён после выбора провайдера и внесения защищённых ключей. AI-ответы идут через server-side GigaChat-2: ключ хранится только в защищённом секрете проекта, короткоживущий OAuth-токен кэшируется на сервере, а TLS проверяется официальной цепочкой Russian Trusted CA. Drizzle/MySQL хранит пользователей и подготовленные сущности диалогов/сообщений.

## Дизайн

### Варианты

- **Midnight editorial studio** — 0.07: тёмная редакционная студия с крупной типографикой и неоновыми «портретами».
- **Soft glass lounge** — 0.06: светлая стеклянная библиотека с мягкими карточками.
- **Arcade character shelf** — 0.05: яркий игровой каталог с крупными иллюстрациями.

Выбран **Midnight editorial studio**.

### Design Movement

Современная digital-editorial эстетика, смешанная с интерфейсами creative tools: спокойный графитовый фон, крупные фразы, локальные цветовые вспышки вокруг персонажей и чёткие панели для работы.

### Core Principles

1. **Сначала персонаж** — имя, настроение и короткая интонация считываются за секунду.
2. **Разговор ближе каталога** — из карточки в чат можно попасть одним действием.
3. **Лёгкая глубина** — плоская типографика сочетается с мягкими свечениями и «портретными» градиентами.
4. **Мобильная ясность** — в узком экране не теряются навигация, CTA и поле ответа.

### Color Philosophy

Графитовый фон снижает визуальный шум и делает портреты центром внимания. Молочный текст создаёт ощущение журнала, а собственный цвет бренда — **electric lilac #B88CFF** — обозначает действие, интеллект и личное пространство. Живые карточки получают локальные акценты: коралл, лайм, лазурь и янтарь.

### Layout Paradigm

Не центрированная посадочная страница, а «редакционная лента»: узкая левая навигация, широкий контентный холст, боковая зона недавних разговоров. На мобильном это превращается в вертикальный журнал с липкой верхней панелью и нижней навигацией.

### Signature Elements

- Портретные блоки 4:5 с крупными инициалами и цветным свечением.
- Маленькие «живые» индикаторы рядом с персонажами.
- Лиловая линия-подсветка у активного состояния и у поля сообщения.

### Interaction Philosophy

Каждое действие должно обещать следующий понятный шаг: «Открыть чат», «Продолжить», «Создать персонажа». Карточки слегка поднимаются при наведении, но не перегружаются анимацией. Состояние AI-ответа всегда видно через короткое «думает» и три точки.

### Animation

Мягкие 180–240ms transitions для hover/focus. Портреты получают едва заметный radial pulse только на активной карточке. Открытие чата — слайд справа на desktop и fade/slide-up на mobile. Избегать бесконечных декоративных эффектов.

### Typography System

Использовать системный гротеск с плотными заголовками: `Inter, ui-sans-serif, system-ui` для всего интерфейса. Заголовки — 700/800, межстрочный интервал 0.95–1.05; подписи и метаданные — 12–13px с увеличенным tracking.

### Brand Essence

Личное пространство для разговоров с ИИ-персонажами — живое, спокойное и настраиваемое. Черты: любопытный, тёплый, выразительный.

### Brand Voice

Заголовки говорят коротко и уверенно. CTA звучат как приглашение к разговору, а не как техническая команда.

- «Выбери голос, который хочется услышать сегодня».
- «Продолжи разговор с того места, где остановился».

### Wordmark & Logo

Знак — две смещённые лиловые скобки вокруг маленькой искры: символ диалога и «второго голоса». В интерфейсе это компактный квадратный mark рядом с текстовым словом `charactera`.

### Signature Brand Color

Electric lilac `#B88CFF`.

## Структура проекта

- `client/src/pages/Home.tsx` — каталог, авторизация-панель, профиль персонажа и чат.
- `client/src/index.css` — токены midnight editorial studio и responsive layout.
- `server/routers.ts` — auth и chat.send tRPC procedures.
- `server/llm.ts` — server-side вызов встроенной LLM с безопасным fallback.
- `server/db.ts`, `drizzle/schema.ts` — users, characters, conversations, messages.
- `public/manus-routes.json` — маршруты приложения для Preview/публикации.

## MVP-границы

Первый срез должен быть полностью кликабельным даже без OAuth: каталог и демонстрационный чат работают сразу. Авторизация через Google/OAuth использует реальный проектный flow. Номер телефона отображается как подготовленный flow и не отправляет SMS до выбора конкретного провайдера, чтобы не создавать ложную авторизацию. После получения Client ID/секрета Google и реквизитов SMS-провайдера они добавляются только через защищённые настройки проекта.
