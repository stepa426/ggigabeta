GIGA BETA — front-end demo
Откройте index.html в браузере или загрузите всю папку на хостинг.

Реализовано:
- приветствие из трёх слайдов;
- демонстрационный вход по телефону и Google;
- стартовый баланс 0 кристаллов;
- автоматический ежедневный бонус +50 при первом входе за календарный день;
- профиль без установленной аватарки и выбор своей фотографии;
- создание персонажа с отдельной загружаемой аватаркой;
- поиск и каталог персонажей;
- чаты с локальным сохранением истории;
- профиль и демонстрационный магазин.

Важно: Google OAuth, SMS-коды, реальные ответы ИИ, облачная база, загрузка файлов на сервер и платежи требуют backend-интеграции. Текущая демоверсия хранит данные в localStorage текущего браузера. Не размещайте секретные API-ключи в index.html.
