# Анализ предоставленного архива

Архив содержит 1 137 файлов (примерно 184,7 MB распакованного содержимого) и несколько параллельных версий проекта.

## Найденные части

1. `index.html` в корне — самостоятельный мобильный интерфейс GIGA с CSS и JavaScript внутри одного HTML-файла. В `assets/` лежат onboarding-изображения, кристалл, логотипы и аватары.
2. `ggigabeta-main/` — React + TypeScript + Vite + Express/tRPC проект. Есть `Home.tsx`, UI-компоненты, Drizzle/MySQL schema, Firebase client auth и GigaChat server integration.
3. `gigaguru-copy/` и `gigaguru-fixed/gigaguru-copy/` — сохранённые статические сборки Next.js с чанками, CSS и локальными копиями ресурсов.
4. `README.txt` описывает корневой HTML как демонстрационную версию с localStorage.

## Важные выводы

- Корневой HTML сохраняет интерфейс, но Google-вход и SMS были заглушками; баланс и бонус хранились в localStorage; ответы чата были имитацией через setTimeout.
- React-версия уже содержала Firebase Google/Phone client flow и серверный модуль GigaChat, но chat endpoint не требовал Firebase token, а отдельного серверного учёта ежедневных кристаллов не было.
- В React-версии системная инструкция формировалась на сервере, однако API ключи и конфигурация требовали правильной настройки окружения.
- В архиве обнаружен Firebase web config (это публичная клиентская конфигурация), но не обнаружен готовый серверный Firebase service-account JSON или действующий GigaChat API credential.
- Google Play listing не удалось получить автоматически в этой сессии, поэтому визуальная основа нового проекта — мобильный интерфейс и ресурсы из пользовательского архива, а не выдуманные детали недоступной страницы магазина.

## Что изменено в новой сборке

- Сохранён корневой мобильный UI и его изображения.
- Добавлен Express backend.
- Google/SMS login подключены к Firebase Authentication.
- Сервер проверяет Firebase ID token через Firebase Admin.
- Баланс и daily claim хранятся в MySQL, начисление 50 кристаллов защищено уникальным ключом и транзакцией.
- Реальный GigaChat-2 вызывается с сервера; основной системный промпт задаётся только в серверной переменной окружения.
- Убраны фальшивые ответы чата и локальное начисление бонуса.
